The `_pick_seeds` function in `graphify/serve.py` [1] selects starting nodes for BFS graph traversal from candidate nodes scored by `_score_query`. Key mechanics: 1. **Noise Prevention via Gap Ratio**: It enforces a cutoff at `top_score * gap_ratio` (default 0.2). When candidate scores drop more than 80% below the top score, expansion halts, preventing high-frequency noise terms (e.g. generic error words) from displacing specific identifier matches [1]. 2. **Per-Term Guarantee**: Ensures that each distinct search token gets at least one representative seed node, preventing an incidental exact match on one term from starving the other query terms [1]. 3. **Label Deduplication**: Deduplicates seeds by normalized label to prevent duplicate generic route handlers from flooding the BFS [1].
